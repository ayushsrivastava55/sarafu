# Agent Services on Base via x402 ($5,000)

## How We Integrated x402

Sarafu exposes its remittance capabilities as paid API endpoints using Coinbase's x402 protocol. Other agents can discover Sarafu, pay per request in USDC on Base, and get remittance services.

### x402 Implementation

- **`@x402/next` v2.7.0** — Official Coinbase Next.js integration
- **`@x402/core/server`** — `x402ResourceServer` + `HTTPFacilitatorClient`
- **`@x402/evm/exact/server`** — `registerExactEvmScheme` for EVM payment verification
- **Facilitator**: `https://x402.org/facilitator` (testnet, free tier)
- **Payment network**: `eip155:84532` (Base Sepolia)
- **Payment token**: USDC

### Protected Endpoints

| Endpoint | Price | Description |
|----------|-------|-------------|
| `POST /api/quote` | $0.01 | Get real-time FX quote between any two Mento stablecoins |
| `POST /api/remit` | $0.01 | Execute a remittance (requires prior quote) |
| `POST /api/chat` | Free | Interactive chat with the agent (demo) |
| `GET /api/health` | Free | Service status |

### How x402 Works in Sarafu

```
Agent A: "I need to send KES to a recipient in Kenya"
    │
    ├── GET /api/quote → 402 Payment Required
    │   └── PAYMENT-REQUIRED header: { price: $0.01, network: Base Sepolia, payTo: 0x... }
    │
    ├── Agent A signs ERC-3009 TransferWithAuthorization (gasless for client)
    │
    ├── Retries with PAYMENT-SIGNATURE header
    │   └── Facilitator verifies + settles on Base
    │
    └── 200 OK: { quoteId, rate, targetAmount, ... }
```

### Service Discovery

Sarafu publishes standard discovery files:

- **`/.well-known/agent.json`** — Lists tools, x402 support flag
- **`/.well-known/service.json`** — Lists all API routes
- **`/agent-registration.json`** — Full ERC-8004 registration with x402 support

### Code

```typescript
// apps/web/src/lib/server/x402.ts
import { withX402, x402ResourceServer } from "@x402/next";
import { HTTPFacilitatorClient } from "@x402/core/server";
import { registerExactEvmScheme } from "@x402/evm/exact/server";

const server = new x402ResourceServer(
  new HTTPFacilitatorClient({ url: "https://x402.org/facilitator" })
);
registerExactEvmScheme(server);

// Wrap any route handler
export const POST = withX402(handler, routeConfig, server);
```

### Why We Should Win

1. Real `@x402/next` integration, not a mock 402 response — uses Coinbase's facilitator for actual USDC settlement
2. Remittance-as-a-service: any agent can pay $0.01 to get an FX quote or execute a remittance
3. The service is discoverable via `.well-known/agent.json` + ERC-8004 registration
4. Clear value proposition: agents need to move money across borders, Sarafu is the service that does it
